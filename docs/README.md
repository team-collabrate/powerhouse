## 🎯 KEY DECISIONS (All LOCKED - No Debate)

| Decision | Choice | Why |
|----------|--------|-----|
| **Frontend** | React 18 + Next.js | Fast, modern, component-based |
| **Backend** | Node.js + Express | JavaScript everywhere, familiar |
| **Database** | PostgreSQL + Supabase | Reliable, RLS for multi-tenant |
| **Auth** | Supabase JWT | Secure, managed, MFA-ready |
| **Styling** | Tailwind CSS | Fast, utility-first, design tokens |
| **State Management** | Zustand + React Query | Lightweight, perfect for dashboard |
| **Colors** | #5cd65c green, #9933ff purple | Professional, accessible |
| **Font** | Outfit Bold | Geometric, trustworthy |
| **Time Billing** | Internal hours only | Never billed to clients |
| **Payment Processing** | Manual entry only | Zero payment processor overhead |
| **Billing Model** | Contract-based (fixed-price) | Not hourly |
| **MVP Timeline** | 12 weeks | 7 sprints, 4-5 people |
